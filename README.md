# DSLM

Inventory management system for NASA's Deep Space Logistics Module, built for the Gateway lunar station. Tracks cargo transfer bags (CTBs), item locations, NFC tag assignments, and supply chain status across crew and ground operations.

Built with React Native (Expo) and a Node.js sync server.

## Setup

```bash
npm install
npm run dev:all
```

See `server/README.md` for backend setup and API docs, and `docs/` for deployment guides.
